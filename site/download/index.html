Download

Observatory is a desktop app, for macOS, Windows, and Linux. Open this page on your computer to download it.

Observatory doesn't run on ChromeOS itself, but the Linux build runs in ChromeOS's Linux development environment.

For now, Observatory is only built for Macs with Apple silicon. On an Intel Mac, you can build it from source.

Observatory needs a 64-bit computer, and this one looks to be 32-bit.

There isn't a build of Observatory for this computer yet, but you may be able to build it from source.

macOS

Apple silicon · macOS 12 or later

  • .zip Apple Silicon

Unzip it, then drag Observatory into your Applications folder.

Observatory isn't notarized by Apple yet, so macOS won't open it at first. To let it run, run this in Terminal: 

xattr -dr com.apple.quarantine /Applications/Observatory.app

Windows

x64 and arm64 · Windows 10 or later

  • Installer x64
  • Installer arm64
  • .zip (Portable) x64
  • .zip (Portable) arm64

The installer sets Observatory up for your account, with no admin rights needed, and opens it. Or unzip the portable build anywhere and run Observatory.exe.

Observatory isn't code-signed yet, so SmartScreen may stop the installer. Choose More info, then Run anyway.

Linux

x64 and arm64 · Flatpak

  • Flatpak x64
  • Flatpak arm64
  • .zip x64
  • .zip arm64

Open the Flatpak with your software center, or install it from a terminal, in the folder you downloaded it to: 

flatpak install --user Observatory-linux-x64.flatpak

The .zip is the app on its own: unzip it anywhere, and run Observatory inside.

Build it yourself

Observatory is open source, under the MPL-2.0. With Node, pnpm, and Rust installed, clone the repository and run: 

pnpm install && pnpm build.forge

The README has the details.
